    The Hershey fonts are a collection of free vector fonts developed circa 1967 by Dr. A. V. Hershey.

    This hershey-fonts package includes Kamal Mostafa's libhersheyfont (a 2013 GPL C library for loading Hershey font files), a gnuplot front-end and other utility programs, as well as the Hershey font glyph data itself. The fonts were converted from Hershey's original NTIS format to the .jhf Hershey file format by James Hurt.
